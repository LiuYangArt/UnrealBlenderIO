# UCX 自动碰撞（issue #2）

## 使用

1. 安装包含 `wheels/coacd-1.0.14-cp39-abi3-win_amd64.whl` 的 UBIO 扩展 ZIP；当前自动生成发行包支持 Windows x64，Blender 自带 NumPy，无需联网或手动 pip。
2. 选中普通 Blender 网格或 UE 导入网格，在 UBIO 面板的独立 **碰撞生成** 组设置参数，再点击 **生成碰撞**。
3. 参数保存在场景中，随 .blend 文件保存。修改参数不会计算，只有点击生成按钮才重新生成；支持撤销、重做，取消左下角 Adjust Last Operation 的自动重算交互。选择资产的一个组成网格会处理该源资产的全部组成网格。同一源资产的实例共享结果，不与其他源资产合并。
4. 在独立 **UBIO 碰撞** 集合检查绿色线框，可直接编辑凸体。生成成功才替换该资产原有碰撞（包括手工绑定碰撞）；失败保留旧结果。

生成结果复用项目已有的碰撞绑定和实例同步机制，继续使用原有导入导出流程。

## 参数和尺度

所有尺寸按资产局部空间的**米**解释，体积按立方米解释，结合 Blender `scale_length` 换算；实例的位移、旋转和缩放不会改变共享源资产的生成预算。

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| 最大凸体数量 | 16 | 每个源资产总数上限；保留结构需要更多时报告失败 |
| 分解误差 | 0.2 m | CoACD real metric 凹陷容忍度 |
| 最小体积 | 0.000001 m³ | 删除较小的独立碎片 |
| 最小厚度 | 0.005 m | 删除较薄的独立组件；按主轴近似厚度 |
| 小特征尺寸 | 0.1 m | 规则墙体填小孔/细缝、地面压平小凸起；0 关闭 |
| 保留矩形门窗 | 开启 | 对可证明的规则墙体使用精确箱体分块 |
| 地面处理 | 关闭 | 对主要水平面上方的小凸起向内压平，不外扩 |

每个生成凸体最多 64 顶点。通用实体使用唯一后端 CoACD，固定随机种子、不外扩；严格规则墙体使用确定性几何分块，避免凸包封堵门窗。生成后检查封闭、凸性和顶点预算，名称采用 `UCX_<资产名>_<编号>`。

## 已定义的边界

- 精确门窗路径要求：资产局部坐标轴对齐、恒定厚度、正交封闭实体，投影格网最多 4096 单元。任意旋转、曲面或不规则洞口走 CoACD。普通 Blender Mesh 也可直接生成；没有 UE 导入路径时按选中的对象独立分组。
- 开放网格会先在临时 BMesh 中补边界洞，再交给 CoACD；原始场景网格不会修改。纯平面薄片仍会失败；复杂自交和嵌套壳不做布尔修复。
- 小特征填补针对整个连通空区判断，超过阈值的大洞口不会因局部窄支臂而被填补。
- 地面处理只识别主水平支撑面的小凸起，不改斜坡坡度，不自动重建复杂地形或改变大台阶。
- 生成同一源资产时会同步当前场景中的导入会话；若不同会话已有不同几何编辑，明确失败，不任意覆盖其中一份。
- 手工编辑后仍须保持凸体封闭且凸。BP 可见碰撞沿用已有实例同步规则：共享网格；任一实例删除对应凸体时，导出会同步删除该凸体。

## 验证与排查

碰撞生成验证入口：`blender --background --factory-startup --python-exit-code 1 --python tests/collision_integration.py`；预处理验证入口：`tests/preprocess_validation.py`。本地测试和大文件保存在被 Git 忽略的 `artifacts/collision/`，测试代码保留在 `tests/`。

生成日志同时输出 Blender 控制台和会话旁 `logs/collision_<资产路径哈希>.json`，包含耗时、数量、每凸体顶点数、处理前后范围、可证明矩形门窗净宽净高。CoACD 路径不会把精确分块的预估洞口尺寸冒充最终测量。
面板交互验证：`blender --background --factory-startup --python-exit-code 1 --python tests/collision_panel_validation.py`；结果写入 `artifacts/collision/panel_validation.json`。默认参数偏向几米级环境资产的粗碰撞；需要小模型细节时在面板降低分解误差。
